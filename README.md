# GenPic 2 Studio

Offizielle Downloads für Windows und macOS.

## Download

Veröffentlichte Versionen und ihre Änderungen findest du unter [Releases](https://github.com/KSTYER1/genpic-releases/releases).

- **Windows:** Installer für Windows x64.
- **macOS:** Separate Downloads für Intel und Apple Silicon.

Installierte Versionen mit Update-Unterstützung können neue Versionen direkt in der App herunterladen.

Dieses Repository enthält ausschließlich Downloadinformationen und fertige App-Pakete. Der Anwendungsquellcode ist privat.
